# Dataset

## Source

The transcriptomic dataset used in this study was obtained from the **NCBI Gene Expression Omnibus (GEO)**.

**GEO Accession:** [GSE243625](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE243625)

## Sample Composition

The dataset contains **45 colonic mucosal biopsy samples**:

| Group | Samples |
|---|---:|
| Active Ulcerative Colitis | 15 |
| Inactive Ulcerative Colitis | 15 |
| Healthy Controls | 15 |
| **Total** | **45** |

## Data Type

The study used **gene-level RNA-seq count data** together with sample metadata.

The count matrix was processed for differential expression analysis using DESeq2, with healthy controls used as the reference condition.

## Data Availability

The original GEO dataset is publicly available through the accession link above.

The raw/public dataset is not duplicated in this repository. Users interested in reproducing or extending the analysis should obtain the data directly from GEO and follow the documented analytical workflow.
